# Public PRA Pattern Notes

The expanded quiz uses publicly visible preparation patterns, not claimed leaked exam questions.

## Sources Checked

- [TCS-Xplore-Python public GitHub repository](https://github.com/harshitgupta028/TCS-Xplore-Python) - describes itself as a collection of previous TCS Xplore Python questions and includes recurring domain-style exercises such as employee organisation, bank balance, student marks/grades, project costing, salary increment, university management, palindrome, vowel strings, and prime counting.
- [Public search results for TCS ILP PRA Python](https://www.google.com/search?q=TCS+ILP+PRA+assessment+Python+topics) - public preparation discussions commonly describe PRA as combining objective questions with coding tasks across technologies; exact format and syllabus can vary by batch and year.

## How This Influenced The Quiz

- Added OOP tracing questions around constructors, inheritance, overriding, `super()`, MRO, properties, descriptors, context managers, composition, and shared class state.
- Added fundamentals questions around strings, lists, tuples, sets, dictionaries, slicing, comprehensions, functions, scope, exceptions, iterators, generators, files, JSON, and common Python traps.
- Added domain-flavored patterns that resemble public practice repositories: employee/student/project/bank-style objects, filtering, aggregation, sorting, and validation.

These are practice questions written for concept coverage. They should not be treated as official TCS questions or a guaranteed prediction of a particular PRA paper.
